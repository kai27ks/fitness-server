# 管理端点评记录

日期：2026-11-26

## 一、需求

会员对教练的五星满意度评价（`coach_review`）此前只有会员提交、教练看自己、会员端教练详情看平均分三个入口，管理端看不到。现在管理员需要能查看全部点评记录。

## 二、改动内容

| 文件 | 改动 |
| --- | --- |
| `controller/ReviewController.java` | 新增 `GET /api/admin/reviews`，`AuthUtil.requireAdmin()` 拦截 |
| `service/ReviewService.java` | 新增 `adminReviews(coachId, page, size)`；新增 `toAdminItem`（姓名不脱敏、带手机号）；`coachRating` 改为走 SQL 汇总 `ratingSummary`，不再整表加载 |
| `dto/ReviewDtos.java` | 新增 `AdminReviewItem`、`AdminReviewPage` |
| `docs/会员评价教练五星满意度.md` | 接口表、权限说明、后续可扩展同步 |

数据库无改动，`coach_review` 表沿用 `docs/sql/20261122_coach_review.sql`。

## 三、接口

```
GET /api/admin/reviews?coachId=&page=&size=
权限：仅 ADMIN（教练 / 会员返回 code=400「无权限：需要管理员身份」）
```

| 参数 | 说明 |
| --- | --- |
| `coachId` | 可选，按教练过滤；不传为全店 |
| `page` | 页码，默认 1 |
| `size` | 每页条数，默认 20，最大 100 |

响应：

```json
{
  "code": 0,
  "data": {
    "total": 2,
    "page": 1,
    "size": 20,
    "summary": { "count": 2, "average": 4.5 },
    "items": [
      { "id": 2, "memberName": "毛文坊", "memberPhone": "13800000001", "coachName": "陈筱鹭",
        "courseName": "基础私教", "rating": 5, "bookingTime": "2026-11-19 14:00", "createTime": "2026-11-26 13:33:48" },
      { "id": 1, "memberName": "冯原", "memberPhone": "15259996010", "coachName": "王毅峰",
        "courseName": "力量增肌", "rating": 4, "bookingTime": "2026-11-14 19:00", "createTime": "2026-11-26 13:33:48" }
    ]
  }
}
```

- `summary` 跟随筛选口径：带 `coachId` 时是该教练的汇总，不带是全店汇总。
- 会员姓名管理员端**不脱敏**（管理员本来就可见全部会员资料）；教练端 `/api/coaches/me/reviews` 仍脱敏为「姓**」，未受影响。

## 六、SQL 变更

**本次无 SQL 变更**（无 DDL、无 DML）。依赖表 `coach_review` 早已存在：

```sql
CREATE TABLE IF NOT EXISTS coach_review (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    member_id   BIGINT  NOT NULL COMMENT 'member.id',
    coach_id    BIGINT  NOT NULL COMMENT 'coach.id',
    booking_id  BIGINT  NOT NULL COMMENT 'booking.id，一次课只能评一次',
    rating      TINYINT NOT NULL COMMENT '满意度 1~5 星',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_booking (booking_id),
    KEY idx_coach_time (coach_id, create_time),
    KEY idx_member (member_id)
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT '会员对教练的满意度评价';
```

若某环境尚未建表，先执行 `docs/sql/20261122_coach_review.sql`。

## 七、发布顺序
