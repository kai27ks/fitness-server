# 教练登录账号管理

## 如何找到教练账号

管理员登录后依次进入「我的 → 教练管理」，按教练姓名或登录手机号搜索。列表显示登录手机号或「未开通登录账号」，点击教练进入详情，在「登录账号」卡片查看关联状态、手机号和账号角色。

教练档案在 `coach` 表，登录账号在 `sys_user` 表，通过 `coach.user_id = sys_user.id` 关联。手机号是登录账号，教练姓名不是登录名。没有 `user_id` 的教练只有档案，尚未开通教练登录。

只读核对 SQL（不查询密码）：

```sql
SELECT c.id AS coach_id, c.name, c.user_id,
       u.phone AS login_phone, u.role, u.status AS account_status
FROM coach c
LEFT JOIN sys_user u ON u.id = c.user_id
WHERE c.name = '林珊';
```

## 开通与关联

- 创建新账号：在未关联教练的详情页，选择「开通 / 关联登录账号 → 创建新账号」，填教练本人手机号、8～64位初始密码并确认。后端创建 `COACH` 角色账号并关联当前档案。
- 关联已有账号：选择「关联已有教练账号」，填已有账号手机号。只允许关联 `COACH` 角色，且不能已被另一位教练关联。沿用原密码和账号状态。
- 已关联账号：显示手机号、账号角色及启用状态，提供教练账号密码重置。无法查看原密码。
- 原关联账号丢失：提示关联异常，允许重新创建或关联账号。
- 新增教练：默认勾选「同时开通登录账号」，需要设置初始密码；取消勾选则仅创建档案，并明确提示未开通登录。新增账号不再使用统一默认密码。

教练档案不会因补账号而重建，原有会员归属、课程和预约记录继续使用原教练 ID。已有的管理员兼教练关联保留，账号角色不会被更改；教练账号入口不重置管理员账号密码。

## 权限与数据处理

账号列表、查看、创建、关联及重置密码均仅管理员可调用。教练和会员界面不展示此账号管理卡片，接口也拒绝访问。

密码使用 BCrypt 哈希保存，接口不返回密码或密码哈希，操作日志不记录密码。创建账号和关联档案在同一事务内完成，并锁定教练及目标账号，避免重复关联。重置密码只改变后续账密登录校验，已有会话继续遵循项目现有 JWT 到期机制。

新增接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/admin/coaches/accounts` | 列表页显示账号状态、支持手机号搜索 |
| GET | `/api/admin/coaches/{id}/account` | 查询某教练关联账号 |
| POST | `/api/admin/coaches/{id}/account` | `mode=CREATE/BIND`，创建或关联 |
| PUT | `/api/admin/coaches/{id}/account/password` | 管理员设置教练新密码 |

首次发布需要同时更新后端 `app.jar` 和前端 `dist`，无需修改数据库表结构。外部调用「新增教练」接口且携带 `phone` 时，须同时提供 `initialPassword`。
