## 幂等设计（可重复执行）

1. 有唯一键的表用 `INSERT IGNORE` 兜底：`sys_user(phone)`、`member(user_id/phone)`、`member_package(member_id, course_id)`、`coach_qualification(coach_id, cert_no)`、`coach_leave(coach_id, start_time, end_time)`、`booking(coach_id, active_start_time)`、`coach_review(booking_id)`。
2. 没有唯一键的表（`coach` 档案、`member_session_log`）先 `SET @x = (SELECT COUNT(*) ...)` 判空再插入。
3. **已取消预约例外**：`booking.active_start_time` 对 `CANCELED` 生成为 `NULL`，唯一键拦不住重复，脚本用 `@b_cancel` 变量判空后再插。
4. 全程按手机号 / 姓名解析主键，**不写死 id**，任何已有数据的库上执行都不会串号。

## 执行后核对

```sql
-- 账号与档案（应 5 行）
SELECT u.phone, u.role, COALESCE(m.name, c.name, '-') AS profile_name, mc.name AS bound_coach
FROM sys_user u
LEFT JOIN member m ON m.user_id = u.id
LEFT JOIN coach c ON c.user_id = u.id
LEFT JOIN coach mc ON mc.id = m.coach_id
WHERE u.phone IN ('13700000003','13700000004','13800000001','13900000002','15259996010');

-- 课包与流水对账：net_change 应等于 remain_sessions，purchase 应为 1
SELECT m.name, ct.name AS course, p.total_sessions, p.remain_sessions,
       SUM(l.type='PURCHASE') AS buy, SUM(l.type='CONSUME') AS used, SUM(l.change_sessions) AS net
FROM member_package p
JOIN member m ON m.id = p.member_id
JOIN course_template ct ON ct.id = p.course_id
LEFT JOIN member_session_log l ON l.package_id = p.id
GROUP BY p.id, m.name, ct.name, p.total_sessions, p.remain_sessions;

-- 预约分布：COMPLETED 11 / BOOKED 2 / CANCELED 2
SELECT status, COUNT(*) FROM booking GROUP BY status;

-- 教练请假
SELECT c.name, l.start_time, l.end_time, l.reason
FROM coach_leave l JOIN coach c ON c.id = l.coach_id ORDER BY l.start_time;
```

## 与 `data.sql` 的关系

- `data.sql` 是 **dev profile 的启动种子数据**（`DevDemoInitializer` 把 `RESET_ME` 改成 123456），只在 `spring.sql.init.mode` 非 `never` 时执行；生产 `mode=never`，不会跑。
- `init_accounts.sql` 是**手工执行的初始化脚本**，号段与 `data.sql` 不同（`13700000003/13700000004/15259996010` vs `13800000001/13900000002`），但都会建「陈筱鹭 / 王毅峰 / 毛文坊 / 陈忠辛」，同一个库里两者都跑会出现同一人两条档案（手机号不同不会撞唯一键）。**一个库只用一套**。

## SQL 变更说明

- 本次只有 **DML（INSERT）**，无 DDL 改动；`coach_review`、`member_session_log` 等表已包含在 `docs/sql/all_tables.sql` 中。
- 执行顺序：`all_tables.sql` → `init_accounts.sql`（脚本内部顺序：账号 → 教练档案 → 资质 → 请假 → 会员 → 课程 → 课包 → 预约 → 课时流水 → 评价；流水依赖预约，不能提前）。

## 回滚（只清理本脚本创建的数据）

```sql
SET @phones = '13700000003,13700000004,13800000001,13900000002,15259996010';

DELETE l FROM member_session_log l
JOIN member m ON m.id = l.member_id JOIN sys_user u ON u.id = m.user_id
WHERE FIND_IN_SET(u.phone, @phones);

DELETE r FROM coach_review r
JOIN member m ON m.id = r.member_id JOIN sys_user u ON u.id = m.user_id
WHERE FIND_IN_SET(u.phone, @phones);

DELETE b FROM booking b
JOIN member m ON m.id = b.member_id JOIN sys_user u ON u.id = m.user_id
WHERE FIND_IN_SET(u.phone, @phones);

DELETE p FROM member_package p
JOIN member m ON m.id = p.member_id JOIN sys_user u ON u.id = m.user_id
WHERE FIND_IN_SET(u.phone, @phones);

DELETE m FROM member m JOIN sys_user u ON u.id = m.user_id
WHERE FIND_IN_SET(u.phone, @phones);

DELETE q FROM coach_qualification q JOIN coach c ON c.id = q.coach_id
WHERE c.name IN ('陈筱鹭','王毅峰','林珊','徐正週');
DELETE l FROM coach_leave l JOIN coach c ON c.id = l.coach_id
WHERE c.name IN ('陈筱鹭','王毅峰','林珊','徐正週');
DELETE FROM coach WHERE name IN ('陈筱鹭','王毅峰','林珊','徐正週');

DELETE FROM sys_user WHERE FIND_IN_SET(phone, @phones);
```

注意：表间无数据库外键，回滚顺序必须自上而下（流水 → 评价 → 预约 → 课包 → 会员 → 资质/请假 → 教练 → 账号），否则会留孤儿数据。
