## 执行方式

```bash
# 1) 新库建表
mysql -u root -p -e "CREATE DATABASE jianshenfang DEFAULT CHARACTER SET utf8mb4"
mysql -u root -p jianshenfang < docs/sql/all_tables.sql

# 2) 初始账号 + 演示基础数据
mysql -u root -p jianshenfang < docs/sql/init_accounts.sql
```

脚本特性：

- `INSERT IGNORE` + `NOT EXISTS`，**幂等**，可重复执行；
- 手机号已存在时跳过，**不会覆盖现有账号的密码**（避免把生产账号改成 123456）；
- 会员档案同时校验 `user_id` 与 `phone`，防止唯一键冲突中断脚本。

## 执行后核对

```sql
-- 账号与档案
SELECT u.phone, u.role, u.status, COALESCE(m.name, c.name, '-') AS profile_name, mc.name AS coach_name
FROM sys_user u
LEFT JOIN member m ON m.user_id = u.id
LEFT JOIN coach c ON c.user_id = u.id
LEFT JOIN coach mc ON mc.id = m.coach_id
WHERE u.phone IN ('13800000001','13800000002','13800000011','13800000012',
                  '13900000001','13900000002','13900000003','13900000004','13900000005')
ORDER BY u.role DESC, u.phone;

-- 课包
SELECT m.name, ct.name AS course_name, p.remain_sessions, p.total_price, p.expire_date
FROM member_package p
JOIN member m ON m.id = p.member_id
JOIN course_template ct ON ct.id = p.course_id;
```

## SQL 变更说明

- 本脚本为 **DML（INSERT）**，无 DDL 改动；表结构见 `docs/sql/all_tables.sql`。
- 执行顺序：`all_tables.sql` → `init_accounts.sql`。
- 与自带的 `data.sql` 不冲突（号段不同），但两者都插入账号时请二选一，避免测试数据重复。

## 回滚（只清理本脚本创建的账号）

```sql
-- 课包 → 教练档案 → 会员档案 → 账号
DELETE p FROM member_package p
JOIN member m ON m.id = p.member_id
JOIN sys_user u ON u.id = m.user_id
WHERE u.phone IN ('13900000001','13900000002','13900000003','13900000004','13900000005');

DELETE m FROM member m
JOIN sys_user u ON u.id = m.user_id
WHERE u.phone IN ('13900000001','13900000002','13900000003','13900000004','13900000005');

DELETE c FROM coach c
JOIN sys_user u ON u.id = c.user_id
WHERE u.phone IN ('13800000011','13800000012');

DELETE FROM sys_user
WHERE phone IN ('13800000001','13800000002','13800000011','13800000012',
                '13900000001','13900000002','13900000003','13900000004','13900000005');
```

注意：如果这些账号已经产生预约、评价、课时流水，回滚会留下孤儿引用（表间无数据库外键），测试环境可接受，生产不要执行。
