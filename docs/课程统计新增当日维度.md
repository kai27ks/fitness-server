# 课程统计新增「当日」维度

## 需求

数据报表 → 课程 Tab 的「课程统计」卡片原来只有「总计 / 本月 / 本周」三个范围，缺少「当日」。本次补上按当天统计的消课口径，并在页面上提供切换。

## 口径说明

- 新增 `range=day`：时间窗口为 `今天 00:00:00 ~ 23:59:59`（按 `booking.start_time` 上班时间过滤，不是创建时间）。
- 消课判定不变：`booking.status ∈ (CHECKED_IN, COMPLETED)`；预约数含已取消；取消数取 `CANCELED`。
- 其余「本周 / 本月 / 总计」口径与排序规则保持不变。
- 汇总条（消课 / 预约 / 取消）与课程排序都随所选范围变化；顶部蓝色大卡「累计消课 / 取消率」仍是全量口径，不受切换影响。

## 改动内容

后端：

| 文件 | 改动 |
| --- | --- |
| `service/ReportService.java` | `courseStats(range)` 增加 `day` 分支（`today.atStartOfDay()` ~ `today.atTime(23,59,59)`），非法 range 仍回落为 `total` |

前端：

| 文件 | 改动 |
| --- | --- |
| `src/api/index.ts` | `reportCourseStats` 的 range 类型扩为 `day / week / month / total` |
| `src/views/admin/ReportsView.vue` | 切换按钮改为「当日 / 本周 / 本月 / 总计」，卡片副标题展示当前统计区间（如 `2026-11-18 ~ 2026-11-18`），总计显示「全部时间」；顶部大卡改名为「当日/本周/本月/累计 消课 / 取消率」，取消率按同范围 `totalCanceled / totalBookings` 计算；底部「教练消课排行」改为由当前范围的课程统计聚合（按课程名 + 教练求和、按节数降序），不再读全量接口 |

接口签名不变：

```
GET /api/reports/course-stats?range=day|week|month|total
权限：ADMIN
```

`range=day` 时响应中的 `from` / `to` 都是当天日期。

## 口径一致性检查（补充）

| 范围 | 时间窗口 | 数据来源 |
| --- | --- | --- |
| `day` | 今天 00:00:00 ~ 今天 23:59:59 | 同一次查询，字段完全一致 |
| `week` | 本周一 00:00:00 ~ 本周日 23:59:59 | 同上 |
| `month` | 本月 1 日 00:00:00 ~ 本月末 23:59:59 | 同上 |

三个范围走的是同一段代码，只有 `from` / `to` 不同，汇总、排序、占比计算逻辑完全相同。
需要特别注意两种「看起来没变化」的情况：

1. **后端没有重新部署**：旧版本 `courseStats` 只认 `month` / `week`，其它值一律回落成 `total`，
   页面会显示「（全部时间）」且数字与「总计」相同。判断方法：看卡片副标题括号里的区间，
   选「当日」时应是 `今天 ~ 今天`，显示「全部时间」就是后端还是旧包。
2. **业务数据本身很少**：如果库里总共只有 14 节消课且全部发生在今天，当日/本周/本月/总计会一样，这是正常的。

「本周 / 本月」窗口包含周期内尚未发生的未来预约（已排课但未消课），因此 `预约数` 会包含未来，
`取消率 = 取消数 / 预约数` 会略低于「只算到今天」的口径；这与「当日」（截至今晚 23:59:59）的算法一致，属于既有设计。

## SQL 变更

**本次无 SQL 变更**，不涉及建表、加字段、索引或数据订正，无需执行任何 DDL/DML。

手工核对某日消课（只读，可用于与页面数字比对）：

```sql
-- 当天消课节数（把日期换成要核对的日期）
SELECT COUNT(*) AS classes
FROM booking
WHERE status IN ('CHECKED_IN', 'COMPLETED')
  AND start_time >= '2026-11-18 00:00:00'
  AND start_time <= '2026-11-18 23:59:59';

-- 当天按课程分组的消课节数
SELECT ct.name AS course_name, COUNT(*) AS classes
FROM booking b
LEFT JOIN course_template ct ON ct.id = b.course_id
WHERE b.status IN ('CHECKED_IN', 'COMPLETED')
  AND b.start_time >= '2026-11-18 00:00:00'
  AND b.start_time <= '2026-11-18 23:59:59'
GROUP BY ct.name
ORDER BY classes DESC;

-- 当天预约总数与取消数
SELECT COUNT(*) AS bookings,
       SUM(CASE WHEN status = 'CANCELED' THEN 1 ELSE 0 END) AS canceled
FROM booking
WHERE start_time >= '2026-11-18 00:00:00'
  AND start_time <= '2026-11-18 23:59:59';
```

4. 验证：进入数据报表 → 课程，点「当日」，汇总条应等于上面的核对 SQL 结果；副标题显示当天日期区间；课程列表按当天消课节数排序。
