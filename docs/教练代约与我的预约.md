# 教练代约与我的预约

## 页面入口

- 教练底部「预约」默认打开「我的预约」；顶部切换「我的预约 / 替会员约课」。
- 「我的预约」列出当前教练负责授课的预约，包括会员自行预约和工作人员代约。默认待上课、全部日期；支持日期和状态筛选、取消待上课预约。
- 教练「我的」和工作台均有「我的预约」入口；会员详情的「预约记录」旁增加「替会员约课」快捷入口。
- 管理员使用相同页面，可筛选全部教练，也可按会员当前绑定的教练代约。

前端路径：`/admin/schedule`、`/admin/schedule/new`。会员详情可携带 `?memberId=会员ID` 预选会员。

## 代约流程与规则

1. 搜索、选择会员。教练只会收到本人名下会员的名单。
2. 选择会员的有效课包与上课日期；授课教练由会员绑定关系确定，课程由课包确定。
3. 选择可用时段。已占用、该会员已约、教练请假、已过时间均不可选。
4. 确认会员、教练、课程与时间，再提交。成功后返回当天待上课列表；会员也能在自己的预约中查看。

预约时暂不扣课，沿用开课自动签到并扣减课时的规则。有效课包必须还有剩余课时，且上课日期在课包有效期内。预约成功会发送现有站内通知，并记录 `STAFF_CREATE_BOOKING` 操作日志。

权限由后端校验：教练不能通过更换会员 ID、课包 ID、教练筛选条件绕过限制。创建预约时重新锁定会员并核对教练归属，同时锁定教练、检查请假及双方的重叠预约。取消和补签也检查预约所属教练。

## 接口

| 方法 | 路径（统一前缀 `/api/admin/bookings`） | 用途 |
| --- | --- | --- |
| GET | `/members?keyword=` | 可代约的会员名单 |
| GET | `/members/{memberId}/options` | 会员信息、课包及教练 |
| GET | `/members/{memberId}/slots?packageId=&date=` | 按目标会员查询时段 |
| POST | 空路径 | 提交 `memberId/packageId/date/startTime` |
| GET | 空路径 | 预约列表；教练条件强制限定本人 |

以上接口仅 ADMIN / COACH 可访问。新建预约不接受客户端指定课程或授课教练。

## 已有数据库升级（执行一次）

原 `uk_coach_slot(coach_id, start_time)` 包含已取消预约，导致取消后同一时段仍无法重新预约。现改为使用生成列：取消状态对应 NULL，其余状态对应开始时间，保留取消历史并继续限制重复占用。

已有数据库执行 [20261112_booking_active_slot.sql](sql/20261112_booking_active_slot.sql)。新建数据库的 `schema.sql` 已同步，无需重复执行。脚本必须在连接到正确数据库后执行，执行前按现有发布流程备份。

```sql
USE fitness;
SOURCE /实际上传路径/20261112_booking_active_slot.sql;
```

`SOURCE` 是 MySQL 客户端命令；数据库管理工具可直接执行该文件中的 ALTER TABLE。当前配置与发布脚本不会自动执行此次数据库升级。不要对已有库重新执行整份 `schema.sql`。

本次代码修改未对本地或生产库执行此 ALTER TABLE，发布时需要分别处理已有数据库。

## 验收

- 教练只看到本人授课的预约与名下会员；管理员可看全部。
- 有效课包可成功代约；会员能在自己的待上课预约中看到相同记录。
- 无课包、剩余不足、过期、课程下架或未绑定教练时不能提交。
- 教练请假、双方时间冲突或时段刚被抢占时提示错误并刷新时段。
- 取消后可再次预约该时段，且原取消记录仍保留（依赖上述索引升级）。
- `docs/ui-prototype/coach.html` 提供列表、代约选择与确认三个静态画面；实际页面确认区在代约页内展开。
