# 会员端「我的 → 教练团队 / 联系教练」点击无效修复

日期：2026-11-15

## 一、现象

会员端「我的」页里点「教练团队」（以及同样配置的「联系教练」），页面会直接回到首页顶部，看不到教练列表。

## 二、根因

`src/views/MineView.vue` 的菜单配置里，这两个入口的 `path` 都写成了 `'/'`：

```ts
{ label: '教练团队', path: '/', ... },
{ label: '联系教练', path: '/', ... }
```

模板里用一个三元表达式兜底，把 `'/'` 一律替换成 `/#coaches`：

```html
@click="m.path !== '/' ? router.push(m.path) : router.push('/#coaches')"
```

但 `HomeView.vue` 里教练区块**没有 `id="coaches"` 锚点**，`#coaches` 找不到目标元素，
于是只完成了「跳回首页」这一步，表现得像「点进去就返回」。

## 三、改动内容

| 文件 | 改动 |
| --- | --- |
| `src/views/MineView.vue` | 菜单 path 改为 `/#coaches`（教练团队）、`/#contact`（联系教练）；点击逻辑简化为 `router.push(m.path)`，去掉 `'/'` 的三元判断 |
| `src/views/HomeView.vue` | 「教练团队」「联系我们」两个区块标题加 `id="coaches"` / `id="contact"`；新增 `scrollToHash()`：数据加载完成后 `nextTick` 再 `scrollIntoView`，并 `watch(route.hash)` 支持重复点击 |
| — | 后端、数据库无改动 |

滚动时机：`HomeView` 的教练列表在 `v-if="!loading"` 里，首次进入时 DOM 还没渲染，
所以在 `loading = false` 之后 `await nextTick()` 再滚动，避免「滚不到」。

## 四、验证

1. 会员账号登录 → 「我的」→ 点「教练团队」：应跳到首页并平滑滚动到「教练团队」区块（不回到顶部）
2. 点「联系教练」：滚动到「联系我们」区块
3. 已在首页时再次从「我的」进入，同样能定位（`watch(route.hash)` 兜底）
4. 其它菜单（我的预约 / 我的课包 / 会员风采）行为不变

前端 `npm run build` 已通过（1.09s）。

## 五、SQL 变更

**本次无 SQL 变更**，纯前端路由与模板调整，无需执行任何 DDL/DML。
