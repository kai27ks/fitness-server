## 一、已确认规则

| 决策项 | 结论 |
| --- | --- |
| 表结构 | **方案 2**：课包补 `coach_id` / `source` / `import_batch_id`，另建批次表与原始行归档表 |
| 重复卡 | 合并为一条课包，剩余相加 |
| 完全一致重复行 | 所有字段完全相同 → 自动去重，只保留第一条（本批 2 行：陈倩如、陈沛霖各 5 节） |
| 课程粒度 | 按「课种」建课程模板（16 个），课包记录归属教练 |
| **教练** | **必须先在「教练管理」录入**；导入只按名称对照，不自动创建；缺失教练时预览直接拦截 |
| 缺失字段 | 总课时 = 剩余、金额 = 0、有效期 = 导入日 + 365 天 |
| 默认密码 | 统一 `123456` |
| 已存在会员 | 手机号命中 `member` 或 `sys_user` 即整条跳过 |

## 二、表结构（迁移后）

```
member_package
  + coach_id        BIGINT NULL      课包归属教练
  + source          VARCHAR(20)      NEW / LEGACY_IMPORT
  + import_batch_id BIGINT NULL      迁移批次（KEY idx_pkg_batch）
  （唯一键 uk_member_course 不变）

legacy_import_batch   一次上传一行：文件名、总行数、会员数、课包数、跳过数、失败数、操作人
legacy_import_row     Excel 每一行原样归档：12 个原始字段 + 课种 + 映射到的 member_id / package_id
                      + status(OK/SKIPPED/FAILED) + err_msg
```

完整 DDL 见 `docs/sql/20261115_legacy_member_import.sql`。

## 四、流程

管理端 → 会员管理 → 「📥 批量导入旧会员」→ `/admin/members/import`

1. 选择 .xlsx → 自动**预览**（不写库）
2. 预览内容：数据行 / 会员数 / 课包数 / 异常行、课种清单、**缺失教练（红色，阻断导入）**、待自动创建的课程、样例 30 条、异常行明细
3. 有缺失教练时按钮置灰并提示「请先录入缺失教练」
4. 确认导入 → 事务落库 → 结果页显示批次号、新增会员/课包、跳过、失败明细

## 九、回滚

```sql
-- 按批次回滚（先确认批次号）
DELETE FROM member_package WHERE import_batch_id = ?;
-- 会员与账号需要按批次关联，归档表里能查到 phone
SELECT phone, member_id FROM legacy_import_row WHERE batch_id = ? AND status = 'OK';
```

会员账号与档案未加批次字段，如需彻底回滚，按归档表里的 `phone` 删除对应的 `member` / `sys_user`。

## 十、注意事项

- **默认密码 123456**：导入后通知会员改密；也可走「公众号认领（手机号 + 认领码）」，认领码在会员详情页。
- **金额为 0**：财务报表不包含这批历史卡；如需历史营收，只能补 Excel 金额列后重导（要先清理已导入数据）。
- **有效期 365 天**：从导入日起算。
- **幂等**：重复导入不会重复建档（手机号命中即跳过），可安全重跑。
- **自动去重**：Excel 里所有字段完全相同的行只保留第一条，被去重的行在归档表里记为 `DEDUP`，不会静默丢弃。
- **教练归属已确认：以「教练」列的人名为准**，不按卡名（课程名）里的教练前缀归属。
  - 卡名只用来得到**课种**（去掉教练名前缀，如「王卢磊基础私教」→「基础私教」）
  - 同一会员同一课种合并时，教练取组内剩余课时最多的那个
  - 教练列为空的 140 行，用卡名前缀里的教练名兜底（否则这些卡没有归属）；如需让这些行直接失败，可另行调整
  - 因此卡名教练与教练列不一致的 23 组，最终按「教练列」归并到对应教练名下
- **事务边界**：整批一个事务；单会员失败被捕获并计入失败明细，其余继续。
- **教练名称必须完全一致**（前后空格会被 trim），有别名（如「Gary」与「盖瑞」）时以教练管理里的名字为准。
