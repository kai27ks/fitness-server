## 五、对课包数量的影响

| 合并口径 | 课包数 |
| --- | --- |
| 会员 + 课程（当前实现） | 约 650 |
| 会员 + 课程 + 卡名前缀教练 | 约 661 |

若改为「以卡名教练为准」，同一会员同课种可能出现 2 条课包，需要把
`uk_member_course(member_id, course_id)` 改为 `(member_id, course_id, coach_id)`，
并同步修改增购逻辑（`selectOne` → `selectList`）。

## 六、结论（已确认）

管理员确认：**教练归属按「教练」列的人名，不按卡名（课程名）里的教练前缀**。

- 卡名只用于提取课种（去掉教练名前缀）
- 同一会员同一课种合并，教练取组内剩余课时最多者
- 结果：课包约 650 条，不需要放开唯一键，也不需要额外 DDL
- 完全一致重复行自动去重（已实现，本批 2 行）

保留说明：这意味着约 11 张卡（如谢瑶的王卢磊基础私教 9 节）会归到「教练列」写的人名下，
如果后续发现教练列实际记录的是销售人，需要再调整。

## 七、SQL 变更

本文件为分析结论，不含新增 DDL。若最终选择「以卡名教练为准」，需要的额外 DDL 为：

```sql
ALTER TABLE member_package DROP INDEX uk_member_course;
ALTER TABLE member_package ADD UNIQUE KEY uk_member_course (member_id, course_id, coach_id);
```
