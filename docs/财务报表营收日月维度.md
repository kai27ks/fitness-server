# 财务报表：营收增加「日 / 周」维度

## 需求

数据报表 → 财务 Tab，营收原来只展示「本月总营收 + 累计」，需要补上**今日**、**本周**两个口径，并能在页面上切换。

## 口径定义

营收 = `member_package.total_price` 之和，按**课包购买时间**（`create_time`）统计，与原有财务口径一致。

| range | 时间窗 |
| --- | --- |
| `day` | 今天 00:00:00 ~ 当前时间 |
| `week` | 本周一 00:00:00 ~ 当前时间 |
| `month` | 本月 1 日 00:00:00 ~ 当前时间 |
| `total` | 2000-01-01 ~ 当前时间（累计） |

说明：`sumPrice` 是左闭右开区间（`>= start AND < end`），所以「今日」不含明天零点。

## 接口

```
GET /api/reports/finance?range=day|week|month|total
权限：ADMIN（不变）
```

返回结构（四个营收口径一并返回，前端切换不再发请求）：

```json
{
  "range": "week",
  "totalRevenue": 128600.00,
  "todayRevenue": 9600.00,
  "weekRevenue": 38400.00,
  "monthRevenue": 76800.00,
  "dailyRevenue": [{ "label": "11-16", "value": 0 }],
  "topMembers": [{ "name": "张三", "amount": 9600.0 }]
}
```

- `range` 非法或缺省时回落为 `month`；
- `topMembers`（会员消费排行）按所选 range 的时间窗聚合，前 5 名。

## SQL 变更

**本次没有 SQL 变更**，纯查询口径调整，无需 DDL/DML。

核对用只读 SQL（与页面数字应一致）：

```sql
-- 今日营收
SELECT IFNULL(SUM(total_price), 0) FROM member_package
WHERE create_time >= CURDATE() AND create_time < NOW();

-- 本周营收（周一为一周起点，与 WEEKDAY()=0 对应）
SELECT IFNULL(SUM(total_price), 0) FROM member_package
WHERE create_time >= DATE_SUB(CURDATE(), INTERVAL WEEKDAY(CURDATE()) DAY)
  AND create_time < NOW();

-- 本月营收
SELECT IFNULL(SUM(total_price), 0) FROM member_package
WHERE create_time >= DATE_FORMAT(CURDATE(), '%Y-%m-01') AND create_time < NOW();

-- 累计营收
SELECT IFNULL(SUM(total_price), 0) FROM member_package WHERE create_time < NOW();

-- 本周会员消费排行（与页面 topMembers 对应）
SELECT m.name, SUM(p.total_price) AS amount
FROM member_package p JOIN member m ON m.id = p.member_id
WHERE p.create_time >= DATE_SUB(CURDATE(), INTERVAL WEEKDAY(CURDATE()) DAY)
GROUP BY m.id, m.name
ORDER BY amount DESC
LIMIT 5;
```
