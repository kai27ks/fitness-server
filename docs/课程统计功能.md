# 数据报表 · 课程统计功能

日期：2026-11-15

## 一、需求

在管理端「数据报表」页新增课程统计：

1. 按**所有课程名称**分类汇总，支持 **当日 / 本周 / 本月 / 总计** 四种时间范围切换，按消课节数排序；
2. 在同一时间范围下，每个课程继续按**教练**细分统计。

## 二、统计口径

| 指标 | 说明 |
| --- | --- |
| `classes` 消课节数 | `booking.status` ∈ `CHECKED_IN` / `COMPLETED`，**排序主键** |
| `bookings` 预约次数 | 该课程（或该教练）全部预约记录数，含已取消 |
| `canceled` 取消次数 | `booking.status = CANCELED` |
| `classPercent` 占比 | 该课程消课 ÷ 全部消课 × 100，保留 1 位小数 |
| 时间字段 | `booking.start_time`（上课时间），不是创建时间 |
| 时间窗口 | 当日 = 今天 00:00:00 ~ 23:59:59；本周 = 周一 00:00:00 ~ 周日 23:59:59；本月 = 1 日 00:00:00 ~ 月末 23:59:59；总计 = 全量 |

课程名、教练名都实时从 `course_template` / `coach` 取，取不到时降级为「未知课程」「未知教练」，
避免课程被改名或停用后统计丢失。

## 三、接口

```
GET /api/reports/course-stats?range=day|week|month|total
权限：ADMIN
```

响应示例：

```json
{
  "code": 0,
  "data": {
    "range": "month",
    "from": "2026-11-01",
    "to": "2026-11-30",
    "totalBookings": 132,
    "totalClasses": 118,
    "totalCanceled": 14,
    "courses": [
      {
        "courseName": "普拉提",
        "bookings": 40,
        "classes": 36,
        "canceled": 4,
        "classPercent": 30.5,
        "coaches": [
          { "coachName": "张三", "bookings": 24, "classes": 22, "canceled": 2 },
          { "coachName": "李四", "bookings": 16, "classes": 14, "canceled": 2 }
        ]
      }
    ]
  }
}
```

排序规则：课程按 `classes` 降序 → `bookings` 降序 → 课程名升序；
课程内的教练按 `classes` 降序 → `bookings` 降序 → 教练名升序。

## 五、SQL 变更

**本次无 SQL 变更**，不涉及建表、加字段、索引或数据订正，无需执行任何 DDL/DML。

统计全部基于已有 `booking`、`course_template`、`coach` 表在内存聚合；
单店数据量（万级预约）下性能可接受，若后续需要更快可把聚合下推到 SQL 并加
`booking(start_time)` 复合索引（当前未加）。

## 六、执行顺序

1. 后端重新打包部署（本次有 Java 代码变更）
2. 前端 `npm run build` 后部署 `dist`
3. 管理员登录 → 数据报表 → 课程 Tab，验证：
   - 切换「当日 / 本周 / 本月 / 总计」数字随之变化，「当日」只统计今天已消课的预约
   - 课程按消课节数从高到低排列
   - 点课程能展开对应教练的节数与预约数
   - 无数据时显示「该时间段暂无数据」

## 七、注意事项

- 该接口仅 `ADMIN` 可访问；教练账号打开数据报表会拿到无权限提示（与原有财务/课程报表一致）。
- 「本周」以周一为一周起点（`DayOfWeek.MONDAY`），不是周日。
- 已取消的预约计入 `bookings` 与 `canceled`，但**不计入** `classes`，所以「预约数 ≥ 消课数」是正常的。
- `week` / `month` 窗口按自然周期算（含未来几天），因此当一个自然周/月刚开始时，
  统计区间可能超出「今天」，这不影响已发生的预约统计。
