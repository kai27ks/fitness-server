# 开发维护联系方式

会员端与教练端的「我的」页底部展示「系统维护与技术支持」，默认收起。点击后显示说明、可选署名、电话和邮箱，支持拨号与发送邮件。管理员不显示该入口，接口也不向管理员返回联系方式。

默认联系方式为 `15805080815`、`kai27ks@163.com`。不使用弹窗、首页横幅或强制提示；该入口仅在用户主动查看个人页底部时出现。

## 配置

配置位于 `src/main/resources/application.yml` 的 `app.support` 下。生产环境可在 `/opt/fitness/config/application-prod.yml` 的已有 `app:` 节点下添加 `support:`（不要重复创建 `app:`）：

```yaml
app:
  support:
    enabled: true
    title: 系统维护与技术支持
    description: 使用问题反馈、功能建议或系统开发维护咨询，欢迎联系。
    developer-name: ''
    phone: '15805080815'
    email: 'kai27ks@163.com'
```

`developer-name` 为空时隐藏署名；电话或邮箱为空时分别隐藏对应操作。`enabled: false` 或两种联系方式都为空时隐藏整个入口。修改后执行 `sudo systemctl restart fitness` 生效，无需重新构建前端。

未被外部配置覆盖时，也可使用 `SUPPORT_ENABLED`、`SUPPORT_DEVELOPER_NAME`、`SUPPORT_PHONE`、`SUPPORT_EMAIL` 环境变量覆盖默认值。

## 发布与验证

首次上线需同时发布后端 `app.jar` 和前端 `dist`。后端新增 `GET /api/support`，沿用现有登录校验，只为 `MEMBER`、`COACH` 返回支持信息；关闭、未配置或其他角色返回 `data: null`。

1. 会员登录后进入 `/mine`，展开入口，确认电话与邮件链接正确。
2. 教练登录后进入 `/admin/mine`，确认展示相同入口。
3. 管理员进入 `/admin/mine`，确认不显示入口。
4. 将 `app.support.enabled` 改为 `false` 并重启后端，重新打开「我的」页，确认入口隐藏。
5. 配置信息加载失败时入口隐藏，不影响个人信息、菜单与退出登录功能。
